# Admin Operations

Daily operator flow:

1. Open `/admin/today` to review readiness.
2. Open Match Control for any warning or critical match.
3. Assign Main and Backup IPTV channels.
4. Test individual stream sources from the assigned channel list.
5. Use Mark Live when the real match begins.
6. Use Open, Close, Extend, or Reopen to manage public stream availability.
7. Save score/minute changes throughout the match.
8. Mark Finished when the match ends.

Playlist operator flow:

1. Open `/admin/playlists`.
2. Add an M3U URL, Xtream endpoint, or uploaded M3U.
3. Sync or Reparse the playlist.
4. Search the imported channel catalog from Match Control.
5. Assign channels to matches without exposing raw source URLs in the UI.
